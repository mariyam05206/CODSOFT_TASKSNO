# Password Generator

## CODSOFT -   Task 3

A simple Python application that generates strong and random passwords based on the length specified by the user.

### Features

* User can specify the password length.
* Generates random passwords.
* Uses letters, numbers, and special characters.
* Displays the generated password.

### Technologies Used

* Python

### Python Concepts Used

* `random`
* `string`
* User input
* String manipulation
* Loops

### How to Run
python password_generator.py

Enter the desired password length when prompted, and the program will generate a random password.
