# Simple Calculator

## CODSOFT Internship - Task 2

A simple calculator developed using Python that performs basic arithmetic operations.

### Operations

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Modulus (%)
* Floor Division (//)
* Power (**)

### Technologies Used

* Python

### How to Run

Run the following command in the terminal:

python calculator.py

Then enter two numbers and select the desired operation.
