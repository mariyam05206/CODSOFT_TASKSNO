# To-Do List

## CODSOFT Internship - Task 1

A simple command-line To-Do List application developed using Python. It allows users to manage their tasks by adding, viewing, updating, deleting, and completing tasks.

### Features

* Add new tasks
* View all tasks
* Update existing tasks
* Delete tasks
* Mark tasks as completed
* Shows the status of each task as Pending or Completed

### Technologies Used

* Python

### Python Concepts Used

* Lists
* `while` loop
* `if-elif-else` statements
* User input
* List methods such as `append()` and `pop()`

### How to Run

Open the terminal in the Task 1 folder and run:
python todo.py

### Menu
1. Add Task
2. View Tasks
3. Update Task
4. Delete Task
5. Complete Task

The user can select an option to manage their tasks.
