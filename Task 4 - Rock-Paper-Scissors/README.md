# Rock-Paper-Scissors Game

## CODSOFT Internship - Task 4

A simple command-line Rock-Paper-Scissors game developed using Python. The user plays against the computer, and the winner is decided based on the rules of the game.

### Features

- User can choose Rock, Paper, or Scissors
- Computer makes a random choice
- Determines the winner
- Displays the user's and computer's choices
- Displays whether the user wins, loses, or gets a tie
- Keeps track of the scores
- Allows the user to play multiple rounds

### Technologies Used

- Python

### Python Concepts Used

- `random` module
- Lists
- `while` loop
- `if-elif-else` statements
- User input
- Conditional statements
- Score tracking

### How to Run

Open the terminal in the Task 4 folder and run:

python rock_paper_scissors.py
